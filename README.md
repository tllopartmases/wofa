# wofa
## Instagram (Claude skills)

Aquest repo inclou les 13 skills d'[instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)
(MIT) a `.claude/skills/ig-*`, perquè Claude Code les carregui automàticament en aquest projecte.

- Perfil de veu de Wofa: `.claude/instagram/voice.md` (omple'l primer; totes les skills el llegeixen).
- Fitxers que generen les skills (`swipe.md`, `plan.md`, `log.md`) també van a `.claude/instagram/`.
- Ordres: `/ig-plan`, `/ig-reel`, `/ig-caption`, `/ig-carousel`, `/ig-story`, `/ig-profile`, `/ig-viral`,
  `/ig-human`, `/ig-comment`, `/ig-reply`, `/ig-dm`, `/ig-repurpose`, `/ig-audit`.
- Les skills **no publiquen** a Instagram: generen el contingut i tu el publiques.
